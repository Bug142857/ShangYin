# 老郑分享

一款 Android 端的豆瓣收藏清单管理应用，集影视/图书/游戏收藏、在线观影、番号/本子收藏于一体。

## 界面布局

App 底部双标签切换：

- **表世界**：豆瓣内容 —— 分类搜索栏（影视 / 图书 / 游戏 / 人物）+ 收藏清单
- **里世界**：番号 / 本子 / 漫画（Komiic）/ 游戏（无忧游戏库）/ 图书（Z-Library）入口 + 里世界收藏清单（分别收藏番号视频、本子漫画、Komiic 漫画与游戏）

右上角为设置入口；设置页含主题管理、清单管理、账号管理（云端同步 / 豆瓣登录 / 哔咔登录 / 无忧游戏库登录 / Z-Library 登录）、片源管理、数据管理、清理缓存。

## 功能

### 收藏清单（表世界）
- 影视 / 图书 / 游戏 / 人物分类搜索（数据来自豆瓣）
- 搜索结果一键收藏；已收藏的条目直接显示"已收藏在某某清单"，详情页右上角同步显示收藏状态（对号 / 加号）
- 条目详情数据来自豆瓣：Rexxar 接口优先，接口不可用时自动回退解析网页（演职员表、剧照也有网页兜底，不再整块空白）；简介与基本信息统一清理 HTML 标签，基本信息按「日期 / 地区 / 类型 / 导演 / 主演 / 片长」重排；库里旧的脏数据打开详情会自动重抓修正
- 多级子清单，网格 / 列表双视图，长按拖拽排序
- 清单管理：独立页面，表世界 / 里世界分组树形浏览、重命名、删除（计数含所有子清单），新建时可选归属世界
- 表世界清单封面使用清单名文字色块，界面统一简洁

### 在线观影
- 苹果 CMS V10 采集源聚合搜索播放，内置默认源、支持自定义增删改
- 片源管理：单源测试 / 批量测试（可用·已失效·需外网三态标记）、JSON 导入导出
- 多线路自动过滤 3u8，HLS 硬解播放，倍速 0.75x ~ 3x
- 断点续播、看完自动连播、剧集列表升降序切换并记忆滚动位置
- 播放时屏幕保持常亮，无需手动点按防息屏
- 横屏右侧选集面板、竖屏 16:9 信息面板
- 源资源库按分类浏览全部片源

### 番号（里世界）
- 外网片源目录浏览 + 页内搜索（输入法确认键直接搜索），点击直接播放
- 搜索结果与各源加载状态会话内保留，播放返回不丢失
- 海报右上角红心收藏到里世界清单，清单内点击恢复播放，播放器返回键直接退出

### 本子（里世界）
- 哔咔漫画，需登录哔咔账号（设置 → 账号管理，凭据与哔咔官方 App、haka_comic 等客户端通用）
- 与 haka_comic 一致的双 API 域名自动回退（官方 picacomic 域名优先，需外网环境；失败自动切换 go2778 备用中转），图片域名跟随 API；快速失败（约 30 秒内出结果），失败可一键重试，错误提示需外网环境
- 分类封面网格 + 最近更新，行式卡片列表（[N P] 标题 / 作者 / 分类标签 / 喜欢 / 观看）
- 新到旧 / 旧到新 / 最多喜欢 / 最多观看排序
- 详情页收藏到里世界清单（右上角心形实时高亮）
- 章节列表支持正序 / 倒序切换（跨重启记忆），可整套下载或单章下载；每章下载按钮旁有图片总览按钮，网格浏览本章全部图片、点击进入阅读器放大
- 自动记住每部作品"上次看到"的章节（高亮显示）；阅读器滑到本章末页继续前进会询问下一章（按话数推进，与列表排序无关）
- 全屏阅读器支持左右翻页（可缩放）/ 上下连续滑动两种模式一键切换（**模式选择跨章节、跨重启记忆**），长按保存、缩放；上下滑动模式顶栏占位排版（信息与首图互不遮挡），顶栏显示章节名 + 页码进度 + 快速跳转滑动条（拖动直接跳到想看的页）；翻到末尾有占位提示——还有下一章时继续滑/甩即询问下一章（严格按话数递增，重复或特殊章节不会误跳，最后一页图片加载完成前不会误触发），已是最后一页则告知"已经是最后一页了"
- 会话级缓存：分类、列表、详情、章节即开即用，返回不重新加载；**详情 + 章节列表另有磁盘缓存**（`filesDir/comic_cache/`），App 重启后再打开也先显示缓存内容并在后台静默刷新，不再空等重新联网；二级页系统返回键逐级回退；加载失败可一键重试
- 里世界资源（番号 / 本子）均需要外网网络环境才能正常访问

### 漫画（里世界）
- Komiic 漫画（komiic.com，韩漫 / 国漫条漫）：最近更新 / 热门 / 连载 / 完结筛选同排切换（可再点取消）、全分类筛选、关键词搜索
- 分类筛选支持收起（横滑一行）/ 展开（换行平铺、限高可滚）两种形态一键切换
- 会话级缓存 + 磁盘缓存：详情与章节列表写入 `filesDir/comic_cache/`，返回或 App 重启后再进先秒显缓存、后台静默刷新，不重复空等加载；加载失败可一键重试
- 封面网格 + 章节列表（单行本标记、正序 / 倒序切换且跨重启记忆），点章节直接阅读，可整套或单章下载；同样支持"上次看到"高亮与末页询问下一章
- 阅读器与哔咔本子共用：左右翻页（缩放）/ 上下连续滑动双模式，长按保存当前页；上下滑动模式顶栏占位排版不遮挡内容，翻到末尾有占位提示——有下一章继续滑即询问（话数严格递增防误跳），没有则告知"已经是最后一页了"
- 每章提供图片总览按钮（下载按钮左侧）网格浏览本章全部图片；「查看全部」合并全部章节图片网格浏览，点击进入阅读器；图片量大时底部显示加载进度提示
- 收藏到里世界清单（右上角心形实时高亮），收藏条目点击恢复阅读
- 双主机自动切换（komiic.com / komiic.cc 同服务镜像）+ 浏览器同源请求头，提高网络兼容性；章节图片防盗链已处理（完整路径 Referer 自动注入）

### 游戏（里世界）
- 无忧游戏库（[wygamer.com](https://www.wygamer.com/)，WordPress + Zibll）：关键词搜索、热门资源列表，2 列封面网格 + 加载更多
- 分类筛选支持收起（横滑一行）/ 展开（换行平铺、限高可滚）两种形态一键切换（与其他模块一致）
- 详情页展示封面、分类、游戏大小 / 版本 / 更新日期、正文简介与游戏截图；**截图可点击放大查看**（复用阅读器：缩放 / 长按保存 / 左右翻页）
- 下载：解析站点中转链接得到网盘分享页地址（迅雷 / 百度等），弹窗支持「用浏览器打开」和「复制链接」；同时显示全站统一解压密码（一键复制）
- 登录（设置 → 账号管理 → 无忧游戏库登录）：内嵌 WebView 直接打开站点独立登录页 `user-sign-2?tab=signin`（站点登录带滑块验证码，故走网页登录；不走首页弹窗登录）；**站点在页面加载后无条件弹出「系统公告」弹窗，WebView 里只剩一层黑色遮罩盖住登录表单，已做处理**：预置 `showed_system_notice` Cookie + 加载后注入脚本强制关闭并移除该弹窗与遮罩（多次重试，防止 500ms 后补弹），登录表单与滑块验证可正常操作；登录检测只看 `wordpress_logged_in` Cookie，返回键不再误报"登录成功"
- 登录页 WebView 与手机 Chrome 保持一致：**不伪造 UA**（伪造 UA 会与 WebView 自动发出的 Client Hints 矛盾，被站点反爬判定为机器人；且接口请求与登录页必须同款 UA 才能复用 Cookie）；**放行 `window.open` / `target=_blank`**（站点常用它打开登录或跳转，WebView 默认会静默丢弃，表现为「点了没反应」，现统一在当前窗口打开）；`databaseEnabled` 在 Android 高版本已废弃、不再设置
- **滑块验证弹窗渲染兜底**：站点滑块弹窗依赖主题 CSS，若只在 WebView 里渲染出半透明遮罩而卡片本身透明（CSS 未生效的表现），会自动补一套最简样式（白色卡片 + 可拖动的滑块条），保证能完成验证；弹窗正常渲染时不注入、不影响原样式
- 页面加载超 25 秒会停止转圈并提示，不再无反馈地白屏等待；顶部 ⓘ 按钮可查看**实时**诊断信息（WebView UA / 模块加载情况 / 最近点击落在哪个元素（含链接 href）/ jQuery·fetch·XHR 请求与结果 / JS 错误 / **资源加载失败的具体地址** / 滑块弹窗与卡片尺寸·背景·提示文字 / 页面跳转记录），页面能显示但点不动时点「复制」把诊断文字发我（截图里常带站点图片，容易被内容安全审核拦下）
- 会话级缓存：返回里世界再进不重新加载；加载失败可一键重试
- 抓取方式：站点的 WP REST 接口拿不到封面与下载信息，列表 / 详情走 HTML 解析（Jsoup）；分类表走 WP REST（带资源数，按热门排序）

### 图书（里世界）
- Z-Library 电子书搜索（书名 / 作者 / ISBN）、3 列封面网格 + 加载更多，详情页展示封面、作者、出版信息卡（出版社 / 年份 / 语言 / 格式 / 大小 / 评分）与简介（站点简介里的 HTML 标签会清理成纯文本）
- 下载：走站点自己的下载入口（搜索结果里的 `dl` 令牌 → `/dl/{token}` 页面），点下载先弹系统「保存到…」**由你选目录与文件名**，再写入所选位置并显示实时进度；额度用尽 / 未登录时会显示站点给出的真实原因（下载需登录账号并消耗 Z-Library 每日额度）
- 接口请求走常驻隐藏 WebView 的页面同源 fetch：发请求前先等页面就绪，瞬时失败自动重试；**输入停顿 700ms 会自动预取该关键词**（站点冷启动约 6 秒，同词第二次 <1 秒），按下搜索基本秒出
- 登录（设置 → 账号管理 → Z-Library 登录）：内嵌 WebView 打开站点登录并顺带完成 DiamWall 反爬验证，Cookie（含 `remix_userid` / `remix_userkey`）与 WebView 同款 UA 一起用于接口请求
- 登录页对 DiamWall 做了兼容：**多线路自动回退**（当前线路打不开自动换下一条，也可手动切换，登录成功后把可用线路写回设置）+ 重定向环检测 + 混合内容放行，全线路失败时给出排查提示；返回键不再误报"登录成功"（只有检测到登录 Cookie 才回传成功）
- **线路只认 getzlib.com 的每日验证地址**：打开登录页前先从 `https://getzlib.com/zh` 解析当日验证可用的域名（自动展开为主域 + `zh.` 中文子域），内置地址仅作兜底（`zh.z-lib.sk` / `z-lib.sk`）；登录成功后把真正可用的域名写回设置，接口请求用它
- **直达 `/login` 登录页**：站点首页的「登录」是普通链接，但站点脚本会在 WebView 里接管这次点击且不产生任何可见结果（实测点击后既不跳转也不发请求），故不做「先开首页再点登录」，直接打开 `/login?redirectUrl=...`（实测可直接加载出邮箱 / 密码表单，无滑块）
- **浏览器能打开、App 里打不开时**：登录页右上角有「输入地址」按钮，把浏览器里能打开的那串地址直接粘进来加载（自动记住域名）
- 登录页 WebView 与手机 Chrome 保持一致：**不伪造 UA**（伪造 UA 会与 WebView 自动发出的 Client Hints 矛盾，被 DiamWall 判定为机器人，表现为「手机 Chrome 能打开、App 里一直转圈」；且接口请求与登录页必须同款 UA 才能复用 Cookie）；**放行 `window.open` / `target=_blank`**（落地页的「登录」多用它打开，WebView 默认静默丢弃 → 「点了没反应」，现统一在当前窗口打开）
- 页面加载超 25 秒会停止转圈并提示；顶部 ⓘ 按钮可查看**实时**诊断信息（WebView UA / 模块加载情况 / 最近点击（含链接 href）/ jQuery·fetch·XHR 请求与结果 / JS 错误 / 资源加载失败的具体地址 / 页面跳转记录），若手机 Chrome 能打开而这里打不开，点「复制」把诊断文字发我即可定位

### 离线下载（我的下载）
- 漫画 / 本子详情页可「下载全部」或按章单独下载，后台串行执行，离开页面不中断
- 「我的下载」页展示下载中任务（进度 / 取消 / 失败移除重试）与已下载内容（封面、占用空间、展开章节），设置页也有「下载管理」入口；详情页章节行实时显示下载进度（已完成 / 总张数 + 进度条）
- 取消下载自动清理下载到一半的文件，不留半成品
- 下载目录：应用私有目录（`Android/data/.../files/comics/`），无需存储权限，卸载应用时一并清除
- 已下载章节可离线阅读（应用内直接打开阅读器），阅读中滑到最后一页可继续下一章（未下载的章节会提示）；删除单章或整本前均有确认提示
- 中断后可续传：已下载的图片文件自动跳过

### 其他
- 云端同步：坚果云 WebDAV 数据漫游 + 配置自动备份（豆瓣 Cookie、片源、主题等，卸载重装不丢登录态）
- 深色模式跟随系统，可选主题色
- 图片磁盘缓存管理（封面等图片强制入磁盘缓存：忽略图床的 `no-store` / `no-cache` 响应头与 Last-Modified 缓存键，看过的封面不再重复下载，磁盘上限 150MB 由 LRU 自动淘汰）

## 下载

前往 [Releases](https://github.com/Bug142857/ShangYin/releases) 页面下载最新 APK，安装即可使用。

> 最低支持 Android 8.0（API 26）。

## 构建

```bash
git clone https://github.com/Bug142857/ShangYin.git
```

使用 Android Studio（Ladybug 以上，JDK 21）打开项目，或命令行：

```bash
./gradlew :app:assembleRelease
```

## 技术栈

- Kotlin + Jetpack Compose（Material 3）
- Room 数据库
- Media3 / ExoPlayer（HLS 播放）
- Coil 图片加载
- OkHttp / Retrofit
- kotlinx-serialization
