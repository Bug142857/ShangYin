# 老郑分享

Android 端的个人收藏与在线播放应用：豆瓣清单管理、跨片源在线观影、音乐、电视直播、电子书、漫画，以及番号 / 本子 / 吃瓜 / X站 / P站等需要外网环境的模块，全部收在一个 App 里。

- 最低支持 **Android 8.0（API 26）**
- 首页为模块宫格，入口可自由开关、长按拖动排序
- 横屏 / 车机（如比亚迪车机）自适应列数
- 应用内检查更新：自动择优线路下载，支持息屏下载

## 界面结构

首页只放模块入口，用一条分割线分成两区：

- **分割线以上（国内网络可用）**：清单 · 观影 · 音乐 · 游戏 · 电视 · 吃瓜
- **分割线以下（「以下模块需要外网环境」）**：图书 · 漫画 · 本子 · 番1 · 番2 · 番3 · 番4 · P站 · X站

右上角是设置入口，内含：主题管理、账号管理、数据管理、片源管理、清单管理、模块管理、收藏管理、下载管理、清理缓存、版本更新。

模块入口可在 **设置 → 模块管理** 里开关与拖动排序（关掉的模块只是隐藏入口，收藏与数据都保留）。

## 模块

### 清单（豆瓣收藏）

- 影视 / 图书 / 游戏 / 人物分类搜索，数据来自豆瓣；影视搜索合并两个豆瓣搜索来源提高召回，**老片需要登录豆瓣才能搜到**
- 搜索结果一键收藏；已收藏条目直接显示「已收藏在某某清单」，详情页右上角同步显示收藏状态
- 详情数据 Rexxar 接口优先，接口不可用时回退解析网页（演职员表、剧照同样有网页兜底）；简介清理 HTML 标签，基本信息按「日期 / 地区 / 类型 / 导演 / 主演 / 片长」重排，游戏按「发行日期 / 类型 / 平台 / 开发商」重排
- 多级子清单，网格 / 列表双视图，长按拖拽排序
- 清单管理：树形浏览、重命名、删除，条目计数含所有子孙清单
- 清单封面使用清单名文字色块，界面简洁
- 条目详情里的「在线观看」入口保留，与独立的「观影」模块互不影响

### 观影

- 独立模块：输入片名跨国内可访问的片源搜索，**实时追加**结果（每个源返回即显示），「共 XX 条结果」行右侧可「停止搜索」
- 结果行爱心收藏到独立的**观影收藏**，与清单收藏完全分开
- 苹果 CMS V10 采集源聚合搜索播放，内置默认源，支持自定义增删改
- 片源管理：单源测试 / 批量测试（可用 · 已失效 · 需外网三态标记）、JSON 导入导出
- 多线路自动过滤 3u8，HLS 硬解，倍速 0.75x ~ 3x
- 断点续播、看完自动连播、剧集列表升降序切换
- 播放时屏幕常亮；横屏右侧选集面板，竖屏 16:9 信息面板
- 源资源库按分类浏览全部片源

### 音乐

- 搜索、收藏、下载三个列表都以**整份列表为播放队列**，切歌 / 顺序 / 随机都按当前列表走
- 播放页：歌词常驻（点击歌词可跳转）、可拖动进度条、进度条下只有 5 个按钮——模式切换 / 上一曲 / 播放暂停 / 下一曲 / 收藏
- 播放模式循环：默认单首播放 → 单曲循环 → 顺序播放 → 随机播放，切换时小字提示 1 秒
- 首页底部迷你播放条：上一曲 / 播放暂停 / 下一曲

### 游戏

- 无忧游戏库（wygamer.com）：关键词搜索、热门资源、分类筛选，封面网格 + 加载更多
- 详情页展示封面、分类、大小 / 版本 / 更新日期、简介与游戏截图，截图可点击放大（缩放 / 长按保存 / 左右翻页）
- 下载：解析中转链接得到网盘分享页（迅雷 / 百度等），可「用浏览器打开」或「复制链接」，并显示全站统一解压密码
- 登录（设置 → 账号管理）：内嵌 WebView 打开站点登录页，支持滑块验证；自动处理站点强制弹出的「系统公告」遮罩
- WebView 与手机 Chrome 保持一致（不伪造 UA、放行 `window.open` / `target=_blank`），滑块弹窗渲染异常时自动补最简样式
- 页面加载超 25 秒停止转圈并提示；顶部 ⓘ 可查看实时诊断信息（UA / 模块 / 请求 / JS 错误 / 资源失败地址 / 跳转记录），点不动时可复制诊断文字反馈
- 列表与详情走 HTML 解析，分类表走 WP REST（按资源数排序）

### 电视

- 自定义 M3U / M3U8 电视源：内置默认源（IPv4 直播源，走 gh-proxy 加速），支持网络地址与本地文件导入
- 电视源配置：源的增删改启停、单条 / 全部并发访问测试、导入导出（支持导出的 JSON / 一行一个地址 / M3U 文本 / 订阅链接）
- 分组筛选：收起为横滑一行 chips（带频道数，如「央视（25）」），展开为换行 chips 限高可滚
- 页内搜索：输入频道名回车即搜，只在已导入的源里查找；返回键逐级返回
- 下拉刷新重新解析所有源，频道列表与滚动位置会话内保留
- 点频道直接播放：HLS 走 media3，FLV 走内置解析；同名频道的多条地址作为「线路」菜单可随时切换
- 频道右侧爱心收藏，清单里点条目直接进频道播放（无封面，用频道名文字当封面）
- 播放页自动横屏，竖屏流（宽高比 < 1）保持竖屏铺满；有「刷新」按钮，断流自动重连
- 内置 FFmpeg 软解，MP2 / AC3 等手机系统解码器不支持的音频也能出声；仍不支持时明确提示换线路或换源（含 FFmpeg 原生库，APK 体积约 20 MB）

### 吃瓜

- 51爆料原生列表 / 详情 / 搜索（无 WebView），列表广告、详情按钮墙、横幅、播放器贴片广告全部从源头屏蔽
- 12 个分类 chips（最新 / 学生校园 / 明星黑料 / 反差吃瓜 / 必撸精品 / 每日大赛 / 网黄专区 / 吃瓜猎奇 / 热门混剪 / 寸止挑战 / 无码AV / 探花精选）+ 关键词搜索 + 触底翻页
- 线路自动发现与切换：着陆页解码镜像列表并逐个探活，失败自动重新选线，镜像轮换无需更新 App
- 详情页图文混排原样呈现，图片点击全屏（长按保存）；视频为 HLS 直链，直接进内置播放器，支持断点续播
- 首页顶部显示「上次看到」可一键续看；详情页右上角提供「浏览器打开」兜底

### 番1 ~ 番4

- 外网片源按源拆成四个入口，各自只看对应片源，避免混在一起太杂
- 片源目录浏览 + 页内搜索（输入法确认键直接搜索），点击直接播放
- 搜索结果与各源加载状态会话内保留，播放返回不丢失
- 海报右上角爱心收藏，收藏条目点开自动拉详情播放

### 本子

- 哔咔漫画，**无需手动登录**：内置默认账号，打开即自动静默登录（token 过期自动重登；网络不通时保留登录态并提示检查外网环境）
- 双 API 域名自动回退（官方 picacomic 优先，失败切备用中转），图片域名跟随 API；快速失败（约 30 秒），失败可一键重试
- 分类封面网格 + 最近更新，行式卡片列表（[N P] 标题 / 作者 / 分类标签 / 喜欢 / 观看），支持新到旧 / 旧到新 / 最多喜欢 / 最多观看排序
- 详情页收藏，右上角心形实时高亮
- 章节列表正序 / 倒序切换（跨重启记忆），可整套或单章下载；每章下载按钮旁有图片总览
- 自动记住「上次看到」的章节并高亮；阅读器翻到本章末页会询问下一章（按话数推进，与列表排序无关）
- 阅读器支持左右翻页（可缩放）与上下连续滑动两种模式，一键切换并跨章节、跨重启记忆；上下滑动模式顶栏占位不遮挡内容，显示章节名 + 页码 + 快速跳转滑动条
- 分类、列表、详情、章节会话级缓存；详情 + 章节列表另有磁盘缓存（`filesDir/comic_cache/`），重启后先显示缓存再后台刷新
- 需要外网环境

### 漫画

- Komiic（komiic.com）韩漫 / 国漫：最近更新 / 热门 / 连载 / 完结同排切换（可再点取消）、全分类筛选、关键词搜索
- 分类筛选支持收起（横滑一行）/ 展开（换行平铺、限高可滚）
- 会话级缓存 + 磁盘缓存（`filesDir/comic_cache/`），返回或重启后先秒显缓存、后台静默刷新
- 封面网格 + 章节列表（单行本标记、正序 / 倒序切换且跨重启记忆），点章节直接阅读，可整套或单章下载
- 收藏条目显示更新状态：最新话数大于「上次看到」→ 红底「更新 N 话」，已读完不显示，已完结 → 绿底「已完结」（网格角标 / 列表标题下方）
- 阅读器与本子共用（双模式、长按保存、末页询问下一章）
- 每章图片总览；「查看全部」合并全部章节图片网格浏览
- 双主机自动切换（komiic.com / komiic.cc）+ 浏览器同源请求头，章节图片防盗链已处理

### 图书

- Z-Library 电子书搜索（书名 / 作者 / ISBN），封面网格 + 加载更多；详情页展示封面、作者、出版信息卡（出版社 / 年份 / 语言 / 格式 / 大小 / 评分）与简介
- 下载走站点自己的 `dl` 令牌入口：先弹系统「保存到…」由你选目录与文件名，再写入并显示实时进度；额度用尽 / 未登录时显示站点返回的真实原因
- 详情页显示当日下载额度（已用 X / Y 次），下载完成后自动刷新
- 接口请求走常驻隐藏 WebView 的页面同源 fetch；输入停顿 700ms 自动预取该关键词，按下搜索基本秒出
- 登录：内嵌 WebView 打开站点登录并顺带完成 DiamWall 反爬验证，Cookie 与 WebView 同款 UA 一起用于接口请求
- 登录页多线路自动回退 + 重定向环检测 + 混合内容放行；线路只认 `getzlib.com` 当日验证地址解析出的域名，成功后写回设置
- 直达 `/login` 登录页（首页的登录点击会被站点脚本接管而无反应）；打不开时可用「输入地址」粘贴浏览器里能用的地址
- WebView 不伪造 UA、放行 `window.open` / `target=_blank`；页面加载超 25 秒提示，顶部 ⓘ 提供实时诊断信息

### P站

- pornhub.com 原生网页解析（无 WebView）：搜索 + 排序 tabs（首页 / 最热 / 最多观看 / 最高评分）+ 分类筛选 + 双列网格 + 页码条
- 卡片点击解析 flashvars 直链（HLS）后进内置播放器；需外网环境，部分 IP 段有地区封锁
- 卡片右上角爱心收藏，顶栏「收藏」页统一管理，点条目重新解析播放

### X站

- pektino.com 排行榜（周 / 月 / 总榜）+ 标签筛选，官方 JSON API 原生渲染
- 双列网格 + 数字页码条（相邻页码 + 跳页），卡片点击直接播放（twimg 直链 mp4，无需先过详情）
- 卡片右上角爱心收藏，顶栏「收藏」页统一管理，点条目直接重放

## 收藏体系

- **清单收藏**：豆瓣条目，存入多级清单，由 Room 数据库管理，只在「清单」模块内使用
- **爱心收藏**：观影 / 音乐 / 游戏 / 电视 / 吃瓜 / 图书 / 漫画 / 本子 / 番号 / P站 / X站各自的卡片与详情页右上角「点爱心」快速收藏；点开收藏条目会回到对应形态：
  - 吃瓜存帖子（点开进详情）、X站存直链（离线重放）、P站存条目（自动重新解析）
  - 番号存片源条目（自动拉详情播放）、观影存片源条目（自动拉详情播放）、电视存频道（直接开播）、音乐存歌曲（直接播放）
  - 本子 / 漫画 / 图书 / 游戏存条目（点开进详情）
- 两套收藏互不影响；爱心收藏页长按可确认删除
- **设置 → 收藏管理**：像下载管理一样按模块列出收藏数量，点卡片进入对应模块的收藏页
- 各模块首页顶栏「收藏」进入对应收藏页；收藏页顶栏另有「下载管理」入口（游戏、电视除外）
- 收藏页统一样式：标题 + 计数、「更新 / 歌手（作者）」排序行、52dp 方形封面行；底部挂迷你播放条（仅音乐）
- 爱心收藏随数据导出 / 云同步一起备份与恢复

## 离线下载

- **下载保活**：下载期间启动前台服务并持有 CPU / Wi-Fi 唤醒锁，息屏或切后台继续下载；全部任务结束后自动停止
- 主页「下载管理」为五个文件夹卡（视频 / 漫画 / 本子 / 音乐 / 书籍）：点卡片进入分区列表，行尾「打开系统目录」用系统文件管理器打开该目录
- 分区列表页：视频（下载中任务 + 已下载点击播放）、漫画 / 本子（进度 + 展开逐章离线阅读 + 上次看到）、音乐 / 书籍（文件列表）
- 漫画 / 本子详情页可「下载全部」或按章单独下载，后台串行执行，离开页面不中断；章节行实时显示进度（已完成 / 总张数 + 进度条）
- 取消下载自动清理半成品文件；中断后可续传，已下载图片自动跳过
- 下载目录为应用私有目录（`Android/data/.../files/comics/`），无需存储权限，卸载时一并清除
- 已下载章节可离线阅读，滑到末页可继续下一章（未下载会提示）

## 数据与设置

- **数据管理**：导出 / 导入 JSON，或坚果云 WebDAV 云同步。覆盖收藏条目、清单层级与排序、片源配置、爱心收藏、漫画 / 本子阅读进度与配置快照；本机已下载的媒体文件不在 JSON 内
  - 导入会校验文件格式（误选普通 JSON 不会清空数据），并按备份中实际存在的字段替换（字段存在但为空 = 清空，老备份缺字段 = 保留本机）
  - 恢复前自动备份当前数据，最多保留最近 10 份
- **配置自动备份**：坚果云 WebDAV 配置 + 登录态 / 片源 / 主题等自动写入公共目录 `Download/老郑分享/config_backup.json`，卸载重装不丢登录态
- **账号管理**：豆瓣 / 无忧游戏库 / Z-Library 登录后会向站点服务端核实会话，失效时显示「登录已失效！点这里重新登录」；每张卡片带「去注册」直达站点注册页；哔咔（本子）无需账号设置
- **清理缓存**：图片缓存、HTTP 缓存、吃瓜解密缓存、漫画 / 本子详情缓存、已下载的更新安装包与分享临时文件；不影响收藏、清单、阅读进度
- **主题**：深色模式跟随系统，可选主题色
- 图片强制入磁盘缓存（忽略图床 `no-store` / `no-cache` 与 Last-Modified 缓存键），上限 150MB 由 LRU 自动淘汰

## 应用内更新

- 配置管理 → 版本更新，手动检查（不做启动自动检查）
- 检查顺序：GitHub Releases API → 失败再读仓库根 `version.json`（含镜像回退）
- 点下载后先并发测速 GitHub 直连与镜像（各拉 256KB 样例），自动选最快线路再下整包；选中线路与换线会显示在进度下方
- 每个通道下载完都校验 SHA-256，不通过视为失败并换下一个通道
- 下载走保活前台服务，息屏继续；全部失败才提示打开发布页
- 安装走系统安装器（Android 8+ 需允许「安装未知应用」）

## 横屏 / 车机

- 首页模块宫格、模块管理、收藏管理、下载文件夹与已下载视频网格、番号 / 本子 / 漫画 / 图书 / 游戏 / X站 / P站 / 演职员 / 剧照 / 图片总览等海报网格，都按屏幕宽度自动增加列数
- 配置管理在宽屏下改为双栏，不等滚动即可放下全部入口
- 音乐播放器控制按钮在宽屏居中排列，不会被拉散
- 播放器横屏使用右侧选集面板；App 未锁定屏幕方向，旋转 / 车机横屏由系统决定
- 布局预览页：[docs/ui-redesign/landscape-preview.html](docs/ui-redesign/landscape-preview.html)（可切换六个界面、模拟 600~1920dp 逻辑宽度）

## 构建

```bash
git clone https://github.com/Bug142857/ShangYin.git
```

使用 Android Studio（JDK 21）打开项目，或命令行：

```bash
./gradlew :app:assembleRelease
```

构建产物：`app/build/outputs/apk/release/老郑分享-<版本号>.apk`

## 技术栈

- Kotlin + Jetpack Compose（Material 3）
